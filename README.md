# DevScope

DevScope is a lightweight GitHub-powered developer profile explorer built with vanilla JavaScript.

## Live Site

https://devscope-etxx.onrender.com

## Repository

https://github.com/kennethduron/devscope

## Current Week 05 functionality

- GitHub developer search
- GitHub profile information
- repository cards
- responsive interface
- loading and error handling

## Planned APIs

- GitHub REST API
- Stack Exchange API (future feature, not part of Week 05 completion)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
